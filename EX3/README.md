# 实验三操作说明

## 1. 实验三要完成什么

实验三由两部分组成：

1. 基本题：完成《单片机实验指导.pdf》中的 `3.3 定时/计数器实验` 和 `4.5 电子发声设计实验`。任务书里写到“4.6 电子发声”应是编号排版误差，指导书实际 `4.6` 是点阵 LED。
2. 提高题：使用内部定时器 1，方式 1，50 ms 溢出中断一次；P1.0-P1.7 控制 8 个 LED，按 1-8 秒的指定时序循环；数码管实时显示当前秒数；同时循环播放两首以上乐曲，每首 8 秒或 16 秒。

## 2. 文件对应关系

- `EX3_Timer.c`：基本题 3.3 的定时器实验，P1.0 和 P1.1 输出方波。
- `EX3_Count.c`：基本题 3.3 的计数器实验，T1 每计 10 个外部脉冲翻转 P1.0。
- `EX3_ClkOut_T2.c`：基本题 3.3 的 Timer2 可编程时钟输出实验。
- `EX3_Sound.c`：基本题 4.5 的电子发声实验，P0.0 输出方波驱动扬声器。
- `EX3_Timer_LED_Sound_Advanced.c`：提高题整合程序。
- `Paper/实验三算法流程图_mermaid.md`：实验报告可用的流程图草稿。

## 3. Keil 里怎么做

1. 参照 `EX2` 的做法，在 `EX3` 目录下新建 Keil C51 工程。
2. 器件选择 `SST89E554RC`；如果 Proteus 没有该器件，仿真时可先用兼容 8051 内核的器件替代，但报告里要说明。
3. 每个基本题建议单独建一个工程，分别添加对应 `.c` 文件，避免多个 `main()` 同时参与编译。
4. 在 `Options for Target -> Output` 勾选 `Create HEX File`，方便 Proteus 加载。
5. `Options for Target -> Target` 里确认晶振频率。这里代码按 `11.0592 MHz, 12-clock mode` 计算；如果你的 Proteus 晶振设成 `12 MHz`，提高题的 T1 50 ms 重装值改为 `0x3CB0`。

## 4. Proteus 提高题接线建议

提高题为了仿真清楚，建议这样接：

- P1.0-P1.7 接 8 个 LED，串联限流电阻，LED 按高电平点亮处理。
- P2.0-P2.7 接一位共阴极数码管的 a,b,c,d,e,f,g,dp。
- P3.7 接蜂鸣器或经三极管驱动扬声器。
- 单片机晶振设 `11.0592 MHz`，与源码中的 `TIMER_CLOCK` 和 T1 重装值一致。

如果使用共阳极数码管，把 `EX3_Timer_LED_Sound_Advanced.c` 里的 `seg_cc[]` 每一项取反即可，例如显示 1 的 `0x06` 改为 `~0x06`。

## 5. 调试时看什么

基本题：

- `EX3_Timer.c`：用 Keil Logic Analyzer 或示波器观察 P1.0、P1.1 是否周期翻转。
- `EX3_Count.c`：给 T1 外部计数输入端输入单脉冲，观察 P1.0 是否每 10 次脉冲翻转一次。
- `EX3_ClkOut_T2.c`：观察 P1.0/T2 是否输出 50% 占空比方波。
- `EX3_Sound.c`：运行后 P0.0 应输出不同频率方波，扬声器听到旋律。

提高题：

- 看 P1：第 1 秒 `0x05`，第 2 秒 `0x0A`，第 3 秒 `0x50`，第 4 秒 `0xA0`，第 5 秒 `0x55`，第 6 秒 `0xAA`，第 7 秒 `0xFF`，第 8 秒 `0x00`，然后循环。
- 看 P2：数码管应显示 `1` 到 `8` 循环。
- 听 P3.7：两首 8 秒旋律应循环播放。
