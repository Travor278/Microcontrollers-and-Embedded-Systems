# 基于神经网络的手写数字识别系统

## 摘要

本文设计一种基于野火 STM32 开发板的手写数字识别系统。系统通过触摸屏采集单个数字的手写轨迹，在 LCD 上实时显示笔迹，并将轨迹数据归一化为 28x28 灰度图像。PC 端使用 PyTorch 基于 MNIST 数据集训练单层感知机和多层全连接神经网络，将量化后的权重导出为 C 源文件并部署到 STM32 Flash 中。系统在微控制器端完成前向推理，输出识别结果、置信度和推理耗时，并通过串口上传到上位机。进阶部分设计 TF 卡批量测试流程，对 MNIST 标准测试集和个人手写测试集分别统计准确率和平均运行时间。

关键词：STM32；手写数字识别；MNIST；神经网络；触摸屏；嵌入式推理
