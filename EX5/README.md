# 实验五操作说明

## 1. 实验五要完成什么

实验五对应“串口通讯与 A/D 转换实验”。

基本题：

- 按指导书 `3.7 串口通讯实验`，周期性向上位机发送字符串。
- 按指导书 `4.2 A/D 转换实验`，读取 ADC0809 转换结果。任务书写成 `4.3 A/D`，但本指导书中 `4.2` 才是 A/D，`4.3` 是 D/A。

提高题：

- 实时读取 A/D 转换值。
- 通过串口发送给上位机。
- 下位机实时显示当前 A/D 值。
- 上位机通过串口命令控制电压显示精度。

## 2. 文件对应关系

- `EX5_Serial.c`：串口通讯基本题，发送 `Xi'an Tangdu Corp.`。
- `EX5_ADC0809.c`：A/D 转换基本题，读取 ADC0809 并把原始值输出到 P1。
- `EX5_ADC_Serial_Advanced.c`：提高题，ADC 采样、串口上传、P2/数码管显示、串口精度控制。
- `Paper/实验五算法流程图_mermaid.md`：报告流程图草稿。

## 3. 调试要点

串口：

- 晶振推荐 `12 MHz`。
- 串口配置为方式 1，`TH1=0xFD`，`PCON=0x80` 时波特率约为 `19200 bps`。
- Keil Debug 中打开 `Serial Window #1`，应周期性看到字符串输出。

A/D：

- `STARTAD = XBYTE[0x7F00]` 用于启动转换。
- `ADRESULT = XBYTE[0x7F08]` 用于读取转换结果。
- `ADBUSY = P3.3`，等待其无效后读取结果。
- Debug 时观察变量 `ad_value` 或 P1/P2 口。

提高题串口命令：

- 发送字符 `0`、`1`、`2`、`3` 可设置电压小数位数。
- 上位机收到格式类似 `ADC=128, U=2.50V`。
