# 实验四操作说明

## 1. 实验四要完成什么

实验四对应任务书的“静态存储器/点阵 LED 显示设计实验”。

基本题：

1. 按《单片机实验指导.pdf》`4.1 静态存储器扩展实验`，完成片内 RAM 和外部 RAM 的数据传送。
2. 按指导书 `2.5 数据排序实验`，完成片内 RAM `30H-39H` 的升序排序。
3. 按指导书 `4.6 点阵 LED 显示设计实验`，完成点阵 LED 扫描显示。

提高题：

1. 对片内 RAM `40H-4FH` 和外部 RAM `0000H-000FH` 中的数据分别升序排列。
2. 新实验箱 `16x16` 点阵循环显示自己的名字，并通过开关控制移动方向。
3. 旧实验箱 `8x8` 点阵循环显示自己的学号，并通过开关控制移动方向。

## 2. 文件对应关系

- `EX4_SRAM.c`：静态存储器扩展基本题。
- `EX4_Sort_Internal.c`：片内 RAM `30H-39H` 排序基本题。
- `EX4_Sort_Internal_External_Advanced.c`：片内 `40H-4FH` 和外部 `0000H-000FH` 排序提高题。
- `EX4_DotMatrix_8x8.c`：Proteus 友好的 8x8 点阵滚动显示模板。
- `EX4_DotMatrix_16x16_Template.c`：16x16 新实验箱字模扫描模板，需要按实际实验箱引脚和本人姓名字模调整。
- `Paper/实验四算法流程图_mermaid.md`：报告可用流程图草稿。

## 3. Keil 调试重点

静态存储器：

- 运行 `EX4_SRAM.c`。
- 在 Memory 窗口查看 `D:0x30`、`X:0x0000`、`D:0x40`。
- 正确结果是 `D:30H-3FH`、`X:0000H-000FH`、`D:40H-4FH` 都为 `00H-0FH`。

排序基本题：

- 运行 `EX4_Sort_Internal.c`。
- 在 Memory 窗口查看 `D:0x30`。
- 初始数据为 `09, 11, 05, 31, 20, 16, 01, 1A, 3F, 08`。
- 排序后应为 `01, 05, 08, 09, 11, 16, 1A, 20, 31, 3F`。

排序提高题：

- 运行 `EX4_Sort_Internal_External_Advanced.c`。
- 查看 `D:0x40` 和 `X:0x0000`。
- 两段数据都应由小到大排列。

点阵：

- Proteus 简化仿真可用 `EX4_DotMatrix_8x8.c`。
- P1 接 8 行，P2 接 8 列，P3.2 接方向开关。
- 旧实验箱显示学号时，把 `digit_font` 替换成自己的学号字模。
- 新实验箱 16x16 显示姓名时，把 `name_font` 替换成自己的姓名字模，并按实验箱实际引脚修改驱动映射。
