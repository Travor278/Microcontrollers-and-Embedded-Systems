## 1. 3.1 数字量输入输出实验流程图

```mermaid
flowchart TD
    A([开始]) --> B["初始化变量 i"]
    B --> C["P1 = P1 OR F0H<br/>声明 P1 高 4 位为输入"]
    C --> D["读取 P1 口数据<br/>i = P1"]
    D --> E["高 4 位右移 4 位<br/>P1 = (i >> 4) & 0FH"]
    E --> F{"是否继续运行?"}
    F -->|"是"| C
    F -->|"否"| G([结束])
```

适用说明：
- 对应 `DigitIO.c`。
- 核心逻辑是“高 4 位输入，低 4 位输出显示”。

## 2. 提高题 1：x=0~9 时 y=x² 的 BCD 查表流程图

```mermaid
flowchart TD
    A([开始]) --> B["初始化平方表 SQR"]
    B --> C["从 20H 读取输入 x<br/>x 为 0~9 的 BCD 值"]
    C --> D{"x 是否在 0~9 范围内?"}
    D -->|"是"| E["以 x 为偏移量查平方表"]
    D -->|"否"| H["结果无效或不处理"]
    E --> F["将 y=x² 写入 21H<br/>结果为 BCD 值"]
    F --> G([结束])
    H --> G
```

适用说明：
- 对应 `Exp1_Improve1.asm`。
- 如果老师不强调异常输入处理，报告中可只保留“读取 x -> 查表 -> 输出 y”主路径。

## 3. 提高题 2：LED 左循环、右循环、间隔闪烁流程图

```mermaid
flowchart TD
    A([开始]) --> B["初始化<br/>P1 = 00H<br/>P2 = 0FFH<br/>30H = 01H<br/>31H = 80H<br/>32H = 55H"]
    B --> C["读取 P2 状态"]
    C --> D["低电平有效处理<br/>A = NOT P2<br/>A = A AND 03H"]
    D --> E{"A 的值?"}

    E -->|"01"| F["左循环模式<br/>P1 = 30H<br/>延时<br/>30H 循环左移 1 位"]
    E -->|"02"| G["右循环模式<br/>P1 = 31H<br/>延时<br/>31H 循环右移 1 位"]
    E -->|"03"| H["间隔闪烁模式<br/>P1 = 32H<br/>延时<br/>32H 按位取反"]
    E -->|"00"| I["空闲模式<br/>P1 = 00H"]

    F --> C
    G --> C
    H --> C
    I --> C
```

适用说明：
- 对应 `Exp1_Improve2.asm`。
- 该图最适合放在报告中作为“主算法流程图”，因为它同时体现了初始化、输入判断、模式分支和循环控制。

## 5. 提高题 2 实验线路图（接线示意）

```mermaid
flowchart LR
    subgraph A["TD-51 开发板"]
        P10["P1.0 / P10"]
        P11["P1.1 / P11"]
        P12["P1.2 / P12"]
        P13["P1.3 / P13"]
        P14["P1.4 / P14"]
        P15["P1.5 / P15"]
        P16["P1.6 / P16"]
        P17["P1.7 / P17"]
        P20["P2.0 / P20"]
        P21["P2.1 / P21"]
    end

    subgraph B["开关及 LED 显示单元"]
        L0["LED0"]
        L1["LED1"]
        L2["LED2"]
        L3["LED3"]
        L4["LED4"]
        L5["LED5"]
        L6["LED6"]
        L7["LED7"]
        K0["模式开关 K0"]
        K1["模式开关 K1"]
    end

    P10 --> L0
    P11 --> L1
    P12 --> L2
    P13 --> L3
    P14 --> L4
    P15 --> L5
    P16 --> L6
    P17 --> L7

    P20 --> K0
    P21 --> K1
```

说明：
- `P1.0 ~ P1.7` 分别连接 8 个 LED，用于显示左循环、右循环和间隔闪烁效果。
- `P2.0`、`P2.1` 分别连接两个模式选择开关。
- 按本实验程序约定，模式开关采用低电平有效：
  - 仅 `K0` 有效：左循环
  - 仅 `K1` 有效：右循环
  - `K0` 与 `K1` 同时有效：间隔闪烁
  - 两个开关都无效：LED 熄灭
- 如果实际实验箱丝印使用的是 `D0 ~ D7` 或 `L0 ~ L7`，报告中统一写成 “8 个 LED 显示端” 即可。
