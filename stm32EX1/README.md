# STM32 EX1 提高题代码

本目录实现《野火STM32实验任务书》实验一提高题：

- 模式一：RGB 灯按红、绿、蓝三种纯色循环，每种约 1 秒。
- 模式一按 K1：切换循环方向，例如红 -> 绿 -> 蓝 变为 红 -> 蓝 -> 绿。
- 模式二：RGB 灯显示黄、紫、青、白四种混色。
- 模式二按 K1：切换到下一种混色。
- 任意模式按 K2：在模式一和模式二之间切换。

## 放入 Keil 工程

建议以野火指南者标准库例程「第13章 GPIO输入--按键检测」为基础工程。

1. 把本目录的 `main.c`、`led/bsp_led.c`、`led/bsp_led.h`、`key/bsp_key.c`、`key/bsp_key.h` 放入工程目录。
2. 在 Keil 的 Project 窗口中添加 `main.c`、`led/bsp_led.c`、`key/bsp_key.c`。
3. 在 `Options for Target` -> `C/C++` -> `Include Paths` 中加入本目录、`led`、`key` 三个路径。
4. 如果原工程已经有旧的 `main.c`，只保留一个主函数，避免重复定义 `main`。
5. 编译、下载到野火指南者开发板。

## 引脚说明

参考《STM32库开发实战指南--基于野火指南者开发板》第 12、13 章：

- 红灯 LED1：PB5，低电平点亮。
- 绿灯 LED2：PB0，低电平点亮。
- 蓝灯 LED3：PB1，低电平点亮。
- K1：PA0，按下为高电平。
- K2：PC13，按下为高电平。

`DelayMs()` 使用软件延时，不是精确定时。如果 1 秒偏快或偏慢，可以微调 `main.c` 里 `DelayMs()` 的 `i = 9000` 常数。
