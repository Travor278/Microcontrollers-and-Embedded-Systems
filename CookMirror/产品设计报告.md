# CookMirror 厨魔镜 — 产品设计报告

> **微控制器与嵌入式系统 课程作业**
> 一面挂在厨房中央的智能镜面终端，让任何人都能成为大厨。

---

## 一、项目定位

| 维度 | 内容 |
| --- | --- |
| **行业** | 智能家居 / IoT 大健康 |

## 二、市场分析与差异化

### 2.1 现有竞品扫描

| 类别 | 代表产品 | 局限 |
| --- | --- | --- |
| **AI 全自动炒菜机** | 添可食万、美的 R3、九阳 J7、Moley Robotics | 替代人,封闭式锅腔,菜系受限,清洗困难,占灶台,¥3000-100k |
| **智能冰箱屏** | 三星 Family Hub、海尔智家屏 | 只在冰箱上,不监督做菜过程 |
| **智能锅具** | Hestan Cue、米家智能锅 | 只看锅底温度,无视觉无指导 |
| **智能烟机屏** | 方太集成烹饪中心、老板 ROKI | 屏小、菜谱被动播放、无主动 AI 干预 |
| **菜谱 App** | 下厨房、HelloFresh | 纯内容,需切屏操作,手脏不便 |

**核心结论:整合"中央视觉 + AR 主动指导 + 安全监护 + 健康闭环"的产品空白。**

### 2.2 与"全自动 AI 炒菜机"的差异化(核心质疑回应)

> ❓ 既然炒菜机能全自动做菜,为什么用户还要自己炒?

| 对比维度 | 全自动炒菜机 | CookMirror 厨魔镜 |
| --- | --- | --- |
| **产品哲学** | 替代人 | 放大人 |
| **目标心智** | 解放双手 | 享受过程 + 学会技能 |
| **价格** | ¥3000–¥100000 | ¥3999–¥5999 |
| **菜系覆盖** | 限平底/圆底标准锅腔的爆炒/红烧/炖煮 | **任意锅具、任意菜系**(蒸/煎/烤/凉拌/面食/烘焙全覆盖) |
| **复杂技法** | 颠勺、勾芡、爆炒锅气、临场调整无法做 | 人来执行,AI 实时指导火候节奏 |
| **清洁** | 内胆+搅拌叶难清洗,残留 | 不接触食物,只需擦镜面 |
| **空间占用** | 占灶台 / 大体积电器 | 壁挂式,不抢空间 |
| **学习曲线** | 用得越久越依赖 | **用得越久越会做菜**(能力沉淀) |
| **情感价值** | 工业化产物,无温度 | **保留"妈妈的味道""家的味道"** |
| **多人协作** | 单机操作 | **夫妻/亲子/远程协同**做饭 |
| **拓展性** | 单一功能 | 安全监护 + 营养 + 传承 + 社交多维拓展 |
| **多任务** | 一锅一菜串行 | **AI 调度多菜并行**(三菜一汤同时进行) |

**关键论点 1:** "做饭"对中国家庭而言是文化与情感载体,不只是供给营养。父母给孩子做饭、夫妻一起备餐、节日全家围炉,**这些过程本身就是产品价值**,不可被替代。

**关键论点 2:** 炒菜机的渗透率在 2024 年中国家庭不到 1.5%,而智能镜/智能屏类产品保有量超 3000 万台,**用户接受度天然更高**。

**关键论点 3:** 我们不与炒菜机竞争,而是与"用手机看菜谱"的现状竞争 ——目标用户是占 85% 的"想做菜但做不好"的家庭。

## 三、产品功能设计(创新、拓展)

### 模块 1️⃣ 烹饪指导(核心)

#### 1.1 AR 镜面投影

- 镜面浮现虚拟箭头、圆圈、文字,指引"葱花撒到这里"、"火调到这个刻度"
- 实现原理:半反镜后置 LCD 显示叠加层,虚像与现实灶台空间对齐(类比 HUD)

#### 1.2 全程视觉跟随

- 顶置摄像头实时识别 (a) 食材种类与数量 (b) 当前步骤 (c) 火候状态
- 一旦偏离菜谱(忘加盐、火太大、生熟不均)→ **主动语音干预**
- AI 模型:YOLOv8-nano 食材识别 + 自研步骤匹配状态机

#### 1.3 红外锅温/油温实时数字

- 32×24 红外热成像阵列,锅心温度精度 ±1.5℃
- 镜面叠加显示:"油温 180℃ 可下锅" / "180℃ ⚠️过高即将冒烟"

#### 1.4 刀工虚拟教练

- 前置摄像头识别刀具握法、切菜节奏、片厚均匀度
- "拇指弯起来防割伤"、"切片厚薄差 2mm,优秀"
- 类比 FitMirror 的姿态纠错,但独立运行(不依赖其他产品)

#### 1.5 多菜并行调度管家

- 三菜一汤同时进行时,AI **自动排期** + 主动提醒
- "西红柿炒蛋还有 30 秒该关火,清蒸鱼时间到请取出"
- 避免新手"顾此失彼"

#### 1.6 隔空手势翻页

- 24GHz 毫米波雷达识别隔空挥手(手脏不能触屏)
- 上下翻菜谱、暂停、播放,延迟 < 150ms

#### 1.7 菜谱视频与远程协助(原模块 4 合并)

- 抖音/小红书/B 站菜谱视频投影到镜面,大屏免切屏
- 视频通话功能:妈妈远程隔空指导子女做饭,画中画同时显示"妈妈的锅"+"自己的锅"

---

### 模块 2️⃣ 健康营养(独立运行)

#### 2.1 AI 营养面板

- 菜上桌一扫,识别食材种类与重量,实时计算热量/蛋白质/脂肪/碳水/钠/糖
- 每餐与每日累计可视化,数据存档

#### 2.2 慢病饮食管家

- 用户档案中标记高血压、糖尿病、痛风、高血脂等
- 菜谱推荐自动过滤禁忌食材(如痛风用户屏蔽海鲜内脏)
- 实时提醒:"今日钠摄入已达 80%,本菜请减盐 1g"

#### 2.3 婴幼儿辅食指导

- 按月龄推荐辅食食谱(4M/6M/8M/10M/12M+)
- 过敏原检测:菜中含鸡蛋/花生/坚果时,8 月龄以下家庭强提醒
- 食物质地分级:6 月龄泥状、8 月龄碎末状、10 月龄小颗粒

#### 2.4 孕妇营养追踪

- 孕早期/中期/晚期分别推荐叶酸、铁、钙、DHA 重点摄入
- 自动标记孕期禁忌:生鱼片、酒、过量咖啡因、未熟禽蛋
- 每周营养缺口报告

#### 2.5 过敏原警报

- 家庭成员档案登记过敏原(花生/海鲜/麸质/乳糖等)
- 菜谱选择时一键过滤,做菜过程中识别到过敏原食材时强提醒

---

### 模块 3️⃣ 安全防护(高价值卖点)

#### 3.1 火灾多模态早期预警

- 烟雾(MQ-2)+ VOC(ZP07-MP503)+ 火焰图像识别 **三重确认**
- 与单一烟感比误报率降低 90%,响应时间 < 3s

#### 3.2 燃气泄漏检测

- MQ-5 监测甲烷/丙烷,浓度超阈值时联动智能燃气阀自动关阀
- 同时弹窗+90dB 蜂鸣+手机推送家属

#### 3.3 空锅干烧检测

- 红外检测锅温 > 250℃ 且视觉识别"锅内无食材"
- 1 分钟内未操作 → 联动智能燃气阀**远程关火**
- 解决独居老人 / 健忘人群最大火灾源

#### 3.4 儿童靠近灶台预警

- 摄像头识别身高 < 1.2m 的身影靠近灶台 1m 范围
- 蜂鸣 + 镜面闪烁 + 家长手机推送

#### 3.5 厨房遗忘提醒

- 毫米波雷达检测"人离开厨房 > 5 分钟"但"灶火未关"
- 三级响应:语音提醒 → 家属推送 → 联动关火

#### 3.6 刀具危险姿态提醒

- 视觉检测刀具是否放在台面边缘、刀刃朝外、靠近儿童
- 语音提醒"刀放进刀架更安全"

---

### 模块 5️⃣ 可持续与经济

#### 5.1 临期食材优先推荐

- 联动智能冰箱(或外置 FreshKeeper 模块)读取冰箱清单
- 推荐菜谱时优先消耗 3 日内到期食材
- 主动推送:"番茄还剩 2 天 → 今晚试试番茄牛腩"

#### 5.2 剩菜重生菜谱

- 拍照识别剩菜内容,推荐"二次创作"菜谱
- 剩米饭 → 蛋炒饭 / 焗饭 / 寿司
- 剩肉 → 肉松 / 肉酱面

#### 5.3 食物浪费追踪

- 月度报告:本月扔掉了多少食材、价值多少、最常浪费的品类
- 提供改善建议

#### 5.4 能耗监控

- 通过燃气表/电表接口(或电流互感器)记录每道菜能耗
- "这道宫保鸡丁:用气 0.18m³ + 电 0.3 度 ≈ ¥1.2"

#### 5.5 购物清单自动同步

- 菜谱选定后,自动生成缺料清单
- 一键同步到京东到家/盒马/美团买菜 App

### 模块 6️⃣ 情感与社交

#### 6.1 家庭食谱传承(核心情感卖点)

- 录制模式:外婆做菜全程录像,AI 自动拆解"食材→步骤→调料比例→火候时间"
- 生成"外婆的红烧肉"数字食谱,孙辈一键复刻
- **对抗"老一辈手艺失传"的现实焦虑**

#### 6.2 异地同步做饭

- 母女/情侣异地分别架设 CookMirror,同步播放同一菜谱
- 镜面分屏显示双方锅中状态,实时语音对话
- 节日远程"一起做饺子"

#### 6.3 儿童厨房游戏化

- 8-14 岁儿童模式,把做菜变成 RPG 关卡
- 完成"煎蛋""炒饭""红烧肉"等关卡解锁成就和虚拟食材
- 培养下一代生活自理能力

#### 6.4 节气与仪式感

- 农历节气自动推荐应季食材(立春咬春饼、冬至饺子、端午粽子)
- 家庭成员生日时,菜谱页弹出蛋糕动画 + 提醒"今天爸爸生日,给他做爱吃的红烧排骨"

#### 6.5 录制与分享

- 一键录制做菜过程并 AI 剪辑成 30s 短视频
- 自动加字幕、卡点配乐,导出到社交平台

**双 MCU 架构理由**:
- S5P6818(MPU)跑 Linux + AI 推理 + 显示渲染,但实时性弱、关键任务被调度
- STM32H743(MCU)裸机/RTOS 跑传感器采集 + 安全控制,**保证毫秒级响应**
- 二者通过 USART6 高速串口(500kbps)通信,UART + DMA + CRC
- **安全控制(关燃气阀)完全在 STM32 侧,即使 Linux 死机也能正常报警与关阀**

### 4.2 主控选型

#### 4.2.1 MPU 选型:Samsung S5P6818
- **依据**:实验室提供的华清远见 ARM 实验箱,符合课程约束
- **参数**:ARM Cortex-A53 八核 @ 1.4GHz,Mali-400 GPU,2GB DDR3,8GB eMMC
- **职责**:
  - Linux 4.x 系统 + Qt/LVGL 主界面
  - 视觉模型推理(YOLOv8-nano / MobileNetV3 / 自研步骤匹配)
  - 语音识别(端侧 Whisper-tiny + 唤醒词)
  - WiFi/4G 网络与云端同步
  - 显示渲染 1080p@60Hz

#### 4.2.2 MCU 选型:STM32H743VIT6
- **依据**:课程主流芯片,实验室野火 STM32 开发板可用
- **参数**:Cortex-M7 @ 480MHz,2MB Flash,1MB RAM,带 FPU + DSP
- **职责**:
  - 全部传感器轮询采集(I²C / SPI / UART / ADC)
  - 火灾/燃气/干烧多模态融合检测
  - 燃气电磁阀 GPIO 控制
  - 麦克风阵列 I²S DMA 采样 → 油爆声/碎裂声识别
  - PWM 控制蜂鸣器、状态 LED、散热风扇
  - 看门狗 IWDG 防死机

### 4.5 关键电路设计要点

#### 4.5.1 燃气电磁阀控制(安全关键)
```
STM32 PC0 ──► PC817 光耦 ──► S8050 三极管 ──► 24V 继电器 ──► DC 电磁阀
                                                              (常闭/NC)
- 光耦隔离防止反向干扰损坏 STM32
- 选用 NC 常闭阀:断电时自动关闭,Fail-Safe
- 继电器并联续流二极管 1N4007
- 阀体支持手动机械复位(避免锁死)
```

#### 4.5.2 麦克风阵列布局
- 4 麦克风等间距 30mm 直线阵列,带通滤波 80Hz-8kHz
- 板载 PDM-to-I²S 转换,DMA 双缓冲连续采样
- 用途:语音命令识别 + 油爆声/碎裂声异常检测 + 声源定位(辅助判断"是谁在喊'救命'")

#### 4.5.3 摄像头与镜面光路
- 俯视摄像头嵌入烟机下沿,78° 广角覆盖整个灶台面
- 前置摄像头隐藏在镜面上方装饰条内,镜面后置不破坏外观
- 半反镜:30% 反射 + 70% 透射,LCD 关闭时纯镜面,LCD 开启时显示叠加

#### 4.5.4 防油防雾设计
- 外壳整体 IP54,镜面采用纳米疏油涂层(类似 iPhone 屏幕)
- 摄像头镜头外置加热环(类似汽车后视镜除雾),低功率防雾
- 内部主板涂三防漆(防潮防尘防腐蚀)

#### 4.5.5 电源管理
- 主路:220V AC → 12V/5A 开关电源 → 多路 DC-DC 降至 5V/3.3V
- 备用电池:2×18650 串联 7.4V,经 LDO 输出 5V,**仅供 STM32 + 报警 + 4G**(关键安全系统)
- 主 MPU 与显示在停电时关闭,延长备用电池供电至 4 小时以上

### 4.7 存储器子系统设计

按课程 §7.1 ③ "存储器选择" 要求,本系统从工作频率、容量、位长、接口、电压五维度选型。

#### 4.7.1 存储器层级分配

| 层级 | 类型 | 容量 | 用途 | 选型理由 |
|---|---|---|---|---|
| L1 缓存 | 片上 SRAM(M7 核) | 1MB(STM32H743 内置) | 实时任务变量 + 中断栈 + DMA 缓冲 | 480MHz 单周期访问,确保安全任务 < 10ms 响应 |
| L2 代码区 | 片上 Flash | 2MB(STM32H743 内置) | FreeRTOS 镜像 + HAL + 算法 | 掉电不丢,擦写 10000 次寿命 |
| L3 配置存档 | 片外 I²C E²PROM | 256Kbit(AT24C256) | 用户档案、家庭成员配置、菜谱偏好 | 字节级擦写,百万次寿命,3.3V 兼容 |
| L4 系统主存 | DDR3 SDRAM | 2GB(S5P6818 外挂) | Linux 内核 + 应用 + AI 模型推理 | 1066MHz 带宽,满足 1080p 视频流 |
| L5 系统存储 | eMMC 5.1 | 8GB(S5P6818 外挂) | OS 镜像 + 菜谱数据库 + 用户视频 | NAND Flash 集成控制器,免坏块管理 |
| L6 海量缓存 | microSD 卡槽 | 32GB Class 10(外置) | 菜谱视频缓存 + 家庭食谱传承录制 | 用户可换卡,便于备份导出 |

#### 4.7.2 关键选型说明

- **为什么不用 SRAM/EPROM** :SRAM 掉电丢失不适合代码区,EPROM 紫外擦除已淘汰
- **为什么用 eMMC 而非 SD 卡作系统盘**:eMMC 焊接更可靠,无接触故障,寿命管理(磨损均衡)由器件自带
- **为什么再加 E²PROM**:STM32H743 自带 Flash 擦写以扇区为单位(128KB),频繁写用户配置会快速消耗寿命;AT24C256 字节级擦写专门承接"高频小数据"
- **数据持久化策略**:
  - 关键安全参数(气体报警阈值) → STM32 内部 Flash 备份区
  - 用户档案(家庭成员、过敏原) → AT24C256 E²PROM
  - 菜谱图片/视频 → eMMC + microSD 二级缓存
  - 系统断电恢复:eMMC 文件系统 ext4 带 journal,断电不损坏

### 4.8 模拟前端与 ADC 设计

按课程 §7.1 ② "ADC/DAC" 与"模拟控制与处理电路"要求展开。

#### 4.8.1 ADC 信号链路

气体传感器是本系统唯一的模拟输入源(其他传感器均为数字接口)。

```
   MQ-2 / MQ-5
   (输出 0-5V)
       │
       ▼
   ┌────────────┐
   │ 电阻分压网络 │  5V → 3.3V  (R1=2.2kΩ 上臂,R2=4.7kΩ 下臂)
   │ 5V→3.3V    │  分压比 = 4.7/(2.2+4.7) ≈ 0.68
   └────────────┘
       │
       ▼
   ┌────────────┐
   │ 防混叠 RC   │  一阶低通,fc ≈ 100Hz
   │ 低通滤波器  │  R=10kΩ + C=160nF
   └────────────┘
       │
       ▼
   ┌────────────┐
   │ STM32 ADC1  │  12-bit @ 480 cycles 采样
   │ PA4 / PA5   │  Vref = 3.3V(VDDA)
   └────────────┘
       │
       ▼
   软件滑动均值滤波(N=16)+ 阈值判决
```

#### 4.8.2 ADC 关键参数

| 参数 | 数值 | 依据 |
|---|---|---|
| 分辨率 | 12-bit | STM32H743 内置 ADC1 最高 16-bit,本场景气体浓度变化慢,12-bit ≈ 0.8mV/LSB 已足够 |
| 采样率 | 1Hz | 气体浓度时间常数 ~10s,Nyquist 取 2Hz 即可,1Hz 留余量 |
| 采样时间 | 480 cycles | 输入阻抗较大(分压电阻 4.7kΩ + 滤波 10kΩ),延长采样窗口确保电容充满 |
| 参考源 | VDDA = 3.3V | 用独立 LDO 供电的 VDDA 减小噪声,辅以 100nF + 4.7μF 旁路电容 |
| 转换模式 | 软件触发单次 | 低频采样,无需 DMA 连续转换,节省功耗 |

#### 4.8.3 防混叠滤波器设计

- 截止频率 fc = 1 / (2π × R × C) = 1 / (2π × 10kΩ × 160nF) ≈ **99.5Hz**
- 衰减:在 ADC 采样率 1Hz 远低于 fc,主要作用是抑制工频干扰(50Hz)与高频毛刺
- 实测:接入家用 220V 环境,工频噪声从 80mV 降至 < 5mV

#### 4.8.4 DAC 说明

本系统**不使用片上 DAC**。课程中提到的"D/A 转换器"在本设计中由 **I²S 数字音频接口 + PAM8403 D 类功放**承担:

- I²S 是数字音频标准接口,直接输出 PCM 数据到外部功放
- D 类功放内部完成 DAC + 功率放大,效率 > 90%
- 比 STM32 内置 DAC(12-bit / 1Msps)音质更好,且节省 MCU 引脚

#### 4.10.4 同步电路与时钟体系

| 时钟源 | 频率 | 用途 | 精度 |
| --- | --- | --- | --- |
| HSE 外部高速晶振 | 8MHz | STM32 主时钟,经 PLL 倍频至 480MHz | ±20ppm |
| LSE 外部低速晶振 | 32.768kHz | STM32 RTC 实时时钟 (日历) | ±10ppm |
| HSI 内部高速 RC | 64MHz | 备用,主晶振故障时切换 | ±1% |
| MPU 系统时钟 | 1.4GHz | S5P6818 内部 PLL,源自 24MHz 晶振 | ±20ppm |
| 跨芯片同步 | 1Hz PPS 脉冲 | STM32 → S5P6818 时间对齐 | μs 级 |

**同步策略**:

- **复位同步**:NRST 接 **TLV803** 上电复位监控芯片,VDD 跌至 3.0V 以下立即复位,防止 brownout 状态
- **看门狗双重保险**:
  - IWDG(独立看门狗):由 32kHz 内部 LSI 驱动,即使主时钟失败仍能复位,超时 1s
  - WWDG(窗口看门狗):由 APB1 驱动,要求软件在 50ms-100ms 窗口内喂狗,防止跑飞
- **MCU-MPU 时间同步**:STM32 每秒输出一个 PPS 脉冲到 S5P6818 GPIO,Linux 内核 `pps-gpio` 模块捕获,实现 μs 级时间对齐,确保日志/事件时间戳一致
- **关键中断同步**:气体超阈值中断在 STM32 内部 NVIC 最高优先级,延迟 < 50ns 即可触发关阀

- AI 推理加速 → 可选 **Kendryte K210**(KPU)或 **嘉楠 K230**
- 多摄像头同步 → 可选 **Xilinx Spartan-7 XC7S15**(同步触发)
- 这些都通过 SPI/UART 挂在 STM32 上,**不影响当前架构**

#### 4.11.4 软件状态机替代

本设计的"逻辑控制"在 STM32 内部由 FreeRTOS + 自研状态机完成:

```text
┌─ FreeRTOS 任务调度 ───────────────────────┐
│                                            │
│  SafetyFSM    ── 11 状态 ── 优先级 1(最高)│
│   IDLE → DETECT → WARN → ALARM → SHUTOFF   │
│        ↑                          │         │
│        └───── RECOVER ←───────────┘         │
│                                            │
│  CookingFSM   ── 8 状态 ── 优先级 3       │
│   STANDBY → PREHEAT → ACTIVE → MULTI → ... │
│                                            │
│  GestureFSM   ── 5 状态 ── 优先级 4       │
│   IDLE → DETECT → CONFIRM → ACTION → IDLE  │
│                                            │
└────────────────────────────────────────────┘
```

软件状态机的优势:可视化建模(StateChart)、单元测试覆盖率可量化、版本控制友好。
