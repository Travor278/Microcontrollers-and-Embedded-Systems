# CookMirror — 立创 EDA + 嘉立创 PCB 制作完全指南

> 从 5 个 Proteus 子电路出发,在**立创 EDA** 重画整机原理图、设计 PCB,提交 **嘉立创 JLCPCB** 打样 + SMT 贴片,5 天后拿到可上电的板子。
>
> **预算预期**:4 层 PCB 打样 ¥80-150 / 5 片,SMT 贴片 ¥150-300 / 板,合计单板 ¥500-800,适合小批量学生项目。

---

## 一、为什么不直接用 Proteus 出 PCB?

| 维度 | Proteus PCB | 立创 EDA |
| --- | --- | --- |
| 元件库 | 通用符号,缺真实物料封装 | 立创商城 **80 万+ 真实物料**,带 3D + 价格 + 库存 |
| 制造对接 | 需自己出 Gerber,转工厂 | **一键发嘉立创**,直接选工艺 + SMT |
| BOM 同步 | 手动 | 一键导出立创商城购物车 |
| 中文支持 | 有限 | 原生中文,文档全 |
| 价格 | 商业软件 | **完全免费** |
| 学习曲线 | 中 | 低(类 AD 但更轻量) |
| 协作 | 本地 | 云端项目,可分享 |

**结论**:Proteus 留作"原理验证 + 仿真演示",PCB 阶段切换到立创 EDA。

### 4.1 元件库的两种用法

| 方式 | 何时用 | 操作 |
| --- | --- | --- |
| **系统库**(基础元件) | 电阻 / 电容 / 二极管 / 三极管 / 排针 | 顶部菜单 **放置 → 元件** 搜索 |

### 4.3 网络标签(Net Label)与端口

- 跨图纸信号(如 +3.3V_D / +5V / GND / I²C_SCL_1 / USART2_TX 等)用**网络端口 (Net Port)** 而非"线连接"
- 立创 EDA 自动按**同名端口**连接不同图纸,**确保命名一致大小写敏感**

**电源命名规范**(全设计统一):

```text
+12V          主电源
+5V           5V 域
+5V_BAT       电池备份 5V 域
+3.3V_D       数字 3.3V
+3.3V_A       模拟 3.3V (VDDA)
+4V_LTE       EC600S 专用 4V
+1.8V_CAM     摄像头 IO
+1.2V_CAM     摄像头核
GND           统一数字地
AGND          模拟地(经磁珠汇入 GND)
```

### 4.4 5 张图纸怎么画(对照 Proteus 子电路)

#### Sheet1 主控最小系统
- 摆放 STM32H743VIT6 LQFP-100,引脚分配按 §4.4 引脚分配表
- 8MHz + 32.768kHz 双晶振 + 22pF×4
- NRST 上拉 + 复位按键 + 100nF 消抖
- BOOT0 下拉
- 每个 VDD 旁放 100nF;VDDA 加 4.7μF
- SWD 调试接口(SWCLK PA14 / SWDIO PA13 + RST + 3.3V + GND)5 pin 排针
- 电源指示 LED (PA0 + 220Ω)

#### Sheet2 火灾安全报警
- MQ-2 / MQ-5 接 +5V,输出经分压 → STM32 PA4/PA5(ADC)
- 蜂鸣器经 2N2222 接 PA8 (PWM 4kHz)
- LED ×3 (PC1 绿 / PC2 黄 / PC3 红) + 220Ω 限流
- 续流二极管 1N4148 反并联蜂鸣器

#### Sheet3 燃气电磁阀关阀
- STM32 PC0 → 1kΩ → PC817 LED(注意 R5 上拉是必须的!)
- PC817 集电极 → 4.7kΩ 上拉至 +5V → R6 (1kΩ) → S8050 基极
- S8050 基极 R4 10kΩ 下拉至 GND
- S8050 集电极 → 继电器线圈(12V 域) // 1N4007 续流
- 继电器 NO 触点 → 电磁阀

#### Sheet4 显示与通信
- LCD 用排针引出(用 21.5" LVDS 外接屏)
- ESP32-S3-WROOM-1:UART2 + EN + BOOT,专用 AMS1117-3.3 LDO,旁路 220μF 钽 + 100nF
- EC600S-CN:UART5 + 5 个控制信号(RST/PWRKEY/STATUS/NETLIGHT/RI)
- nano-SIM 卡座 + USIM 4.7kΩ 上拉
- EC600S 专用 MP1495 DC-DC 4V/2A,输入端 470μF 钽

#### Sheet5 I²C 传感器总线
- SHT40 + BMP280 + AT24C256 共用 I²C1 (PB6/PB7),4.7kΩ 上拉
- MLX90640 独占 I²C2 (PB10/PB11),4.7kΩ 上拉(大数据量)
- 每个 IC 旁放 100nF 退耦

### 4.5 ERC 电气规则检查

完成 5 张图后:**工具 → 编译 / ERC 检查**
- 红色错误必须全部清零(短路 / 悬空 / 网络冲突)
- 黄色警告可忽略**反复确认无影响**的项

1. 顶部菜单 **设计 → 更新 PCB**
2. 弹窗确认 → 所有元件按封装载入 PCB
3. 初始所有元件挤在一起,**先全选移到板框外**
4. 画**板框**(机械层):
   - **A 主控板**:80×60mm 矩形(用 PCB 工具 → 板框)
   - 倒圆角 R3
   - 四角放 M3 安装孔(避免螺丝短路,内层挖空 ¢6mm)

## 六、PCB 设计(8-15 小时,最耗时)

### 6.1 布局原则

| 优先级 | 区域 | 元件 |
| --- | --- | --- |
| 1 | 中央 | STM32H743(关键元件优先定位) |
| 2 | 一角 | 电源转换区(LM2596 / LDO,**远离 ADC/晶振**) |
| 3 | 边缘 | 排针接口(对外信号,便于走排线) |
| 4 | 边缘 | RF 模组(ESP32 / EC600S,**天线朝外**) |
| 5 | 主控旁 | 晶振 + 解耦电容 + 复位电路(**离主控 < 5mm**) |

**禁忌**:
- 模拟和数字元件混放
- 开关电源紧邻 ADC 或晶振
- 天线下方有铜或元件

### 6.2 关键走线规则

| 信号 | 线宽 | 间距 | 备注 |
| --- | --- | --- | --- |
| GND / +3.3V_D / +5V | 20mil | 10mil | 主电源 |
| +12V (继电器) | 30mil | 15mil | 大电流 |
| 信号线 (UART/SPI/I²C) | 8mil | 8mil | 通用 |
| 高速 UART (921.6kbps) | 10mil | 10mil | 包地 |
| ADC 输入 | 12mil | 15mil | 远离开关电源 ≥ 10mm |
| MIPI-CSI 差分 | 5mil + 阻抗 90Ω | - | 由实验箱承担 |

### 6.3 覆铜与接地

- **顶层 + 底层都覆铜接 GND**
- 元件密集区在内层(L2/L3,4 层板)走信号
- 高频区(ESP32/EC600S 天线下方)**严禁覆铜**
- 模拟地(AGND)通过 **0Ω 电阻或磁珠**单点连接到主 GND
- 板边铺一圈"屏蔽地",密集打地过孔(0.3mm 孔径,1mm 间距)

### 6.4 DRC 设计规则检查

**工具 → DRC 检查** → 修复所有红色错误:
- 线距违规
- 过孔 → 焊盘距离
- 元件外形冲突
- 网络未连接

## 七、生成制造文件(15 分钟)

### 7.1 Gerber + 钻孔 (交给嘉立创打样)

1. **制造 → 生成 PCB 制造文件 → Gerber**
2. 选嘉立创格式预设
3. 导出包含:
   - `.GTL` / `.GBL` 顶/底层
   - `.GTS` / `.GBS` 焊膏层
   - `.GTO` / `.GBO` 丝印
   - `.GTP` / `.GBP` 阻焊
   - `.GKO` 板框
   - `.XLN` 钻孔
4. **打包为 ZIP**(嘉立创要求)

### 7.2 BOM + Pick & Place(交给嘉立创 SMT)

1. **制造 → 元件清单 (BOM)** → 导出 Excel
   - 检查所有元件**立创编号 (C 编号)** 都填了
   - 自有库元件可能要补编号
2. **制造 → 坐标文件 (Pick & Place)** → 导出 CSV
   - 提供贴片机的元件坐标 + 旋转角度

## 九、收货验证(2-4 小时)

### 9.1 外观检查

- 板面无划痕、铜露、焊膏残留
- 丝印清晰
- SMT 贴片对位准确(用放大镜)

### 9.2 上电前测试

⚠️ **千万别一上来就插电**!

1. 万用表通断模式:**+12V vs GND 不能短路**(此项不过严重)
2. 万用表通断:**+5V vs GND** / **+3.3V vs GND**
3. 焊点冷焊检查:用镊子轻拨大元件确认稳固

### 9.3 加电烧录

1. 串接限流电源(可调,先设 12V/100mA 限流)
2. 上电观察电源指示 LED 是否亮
3. SWD 接 ST-Link → STM32CubeProgrammer → 烧录最简 LED 闪烁程序
4. 看 LED 闪 = 主控活了 ✓
5. 后续逐模块加电:气体阵列 → 显示 → 通信 → 关阀

### 9.4 飞针测试(嘉立创提供,可选)

- 下单时勾选 **飞针测试 ¥30/批次**
- 嘉立创自动按 Gerber 验证每个网络的连通性
- 出问题时排查神器,推荐给关键项目加

## 十、常见坑与排坑(踩过才懂)

| 坑 | 现象 | 修复 |
| --- | --- | --- |
| 元件库选错封装 | 实物对不上焊盘 | 仔细看封装预览图 + datasheet |
| 中文丝印乱码 | 板上看到 ?? | 改用英文 / 拼音 |
| 钻孔过小 | 嘉立创工程师改图(收费) | 最小 0.3mm,避免 0.2 |
| 网络未连 | 通电不工作 | 强制 ERC 检查 + 飞针测试 |
| 12V 走线太细发热 | 板子热,继电器吸不住 | 主电源 ≥ 30mil |
| 天线下方覆铜 | WiFi/4G 信号弱 | 严禁覆铜,挖空 |
| ESD 损坏 | USB/SIM 接口烧 | 加 TVS 二极管 |
| 阻焊未开 | 测试点焊不上探针 | 测试点要在阻焊层挖窗 |

## 十一、迭代节奏建议

| 阶段 | 内容 | 周期 |
| --- | --- | --- |
| **v1 验证版** | 主控板 A 单板,验证最小系统 + 1-2 个传感器 | 2 周 |
