# 实验六操作说明

## 1. 实验六要完成什么

实验六对应“基于 MCS51 单片机步进电机、直流电机控制实验”。

基本题：

- 按指导书 `5.1 步进电机实验`，用 P0 口输出四相八拍励磁序列控制步进电机。
- 按指导书 `5.2 直流电机 PWM 调速实验`，用 P1.7 输出 PWM 驱动直流电机。

提高题：

- 按键实现直流电机启动、停止、速度增减，速度等级为 0、1、2、3、4。
- 数码管实时显示当前状态。
- 上位机通过串口实时收到电机状态，并可以控制状态。
- 在速度为 0 继续减速，或速度为 4 继续加速时触发报警：声音、灯光、串口发送 `error`。

## 2. 文件对应关系

- `EX6_Stepper.c`：步进电机基本题。
- `EX6_DC_PWM.c`：直流电机 PWM 基本题。
- `EX6_DC_Control_Advanced.c`：直流电机综合控制提高题。
- `EX6.c`：提高题真机脱机运行版，支持按键和上位机串口命令控制。
- `Paper/实验六算法流程图_mermaid.md`：报告流程图草稿。

## 3. 提高题端口约定

- `P1.7`：PWM 输出。
- `P1.0`：报警 LED。
- `P1.1`：报警蜂鸣器。
- `P2`：一位共阴极数码管段码，停止显示 `-`，运行时显示速度 `0-4`。
- `P3.2`：启动键，低电平有效。
- `P3.3`：停止键，低电平有效。
- `P3.4`：加速键，低电平有效。
- `P3.5`：减速键，低电平有效。
- 串口命令：`s` 启动，`p` 停止，`+` 加速，`-` 减速，`0-4` 直接设定速度。

## 4. 调试要点

步进电机：

- 观察 P0 低四位是否按 `01,03,02,06,04,0C,08,09` 循环。
- P3.2 改变方向。

直流 PWM：

- 观察 P1.7 是否输出周期性脉冲。
- 改变高低电平延时值可改变占空比。

提高题：

- Keil Debug 中观察 `running`、`speed`、`alarm_ms`。
- Logic Analyzer 观察 `PWM_OUT`。
- Serial Window #1 观察 `RUN=... SPEED=...` 和 `error`。
